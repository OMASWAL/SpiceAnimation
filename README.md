# SpicyAnimation

This project is a high-performance, visually immersive web application that is built with React and Tailwind CSS, the site leverages GSAP to orchestrate complex, timeline-based 3D animations and scroll-triggered reveals that respond dynamically to user interaction. To elevate the user experience, Locomotive Scroll was integrated to provide a buttery-smooth inertial scrolling effect, seamlessly blending parallax depth with high-end aesthetics. The result is a fluid, responsive digital experience where every transition and movement is meticulously timed for maximum visual impact.
